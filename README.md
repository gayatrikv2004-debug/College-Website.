# College Website

## Project Overview
This project is a College Website developed using HTML, CSS, and JavaScript. It provides information about the college, courses, admissions, events, and contact details through a simple and user-friendly interface.

## Features
- Home Page – Introduction to the college.
- About Page – Information about the college.
- Courses Page – Details of available courses.
- Admission Page – Admission information.
- Gallery Page – College photos and events.
- Contact Page – Contact information.
- Login Page – User login interface.
- Registration Page – New user registration.
- Responsive and user-friendly design.

## Technologies Used
- HTML – Structure of web pages.
- CSS – Styling and layout.
- JavaScript – Interactive functionality.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the different pages of the college website.

## Conclusion
The College Website provides an easy way for students and visitors to access college-related information online. It demonstrates the use of HTML, CSS, and JavaScript in developing a basic website.
